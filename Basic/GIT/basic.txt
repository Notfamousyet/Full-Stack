Git(software): The tool on your computer that saves your history.

GitHub(service): The website where you store and share that history with others.

-- To know branching use
git branch

-- To create a new branch use keywords and add name to it. 
git branch abc

-- To switch branch and to create and switch. 
git checkout abc
git switch -c abc

-- To merge any branch to main 
git merge abc

-- To delete any branch
git branch -d abc

-- To see difference between what previous and after. Here '-' and '+' are used to differentiate what changes are made.To quit only write :q

git stash

-- To get those changes back use 
git stash pop
